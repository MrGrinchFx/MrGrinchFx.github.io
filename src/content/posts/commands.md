### Commands for Fuwari

| Command | Description |
| ------- | ----------- |
| pnpm dev | Runs the test Server |
| pnpm new-post <post_name> | Creates a new post named post_name |
| pnpm format | Formats the code using some internal tool |
| pnpm check | Checks the code for errors |
| pnpm install | Install dependencies |
